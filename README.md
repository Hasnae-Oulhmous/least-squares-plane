# Least-Squares Plane

## Description

This project computes a least-squares plane from a set of 3D points stored in a TXT file.

The plane is defined by:

$$
z = ax + by + c
$$

The project imports the data, computes the coefficients of the least-squares plane, and displays the data points and the fitted plane in 3D.

## Requirements

- **Python 3** .
- **NumPy**.
- **Matplotlib**.
- **Jupyter**.
